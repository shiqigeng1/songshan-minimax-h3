## 九齿独立门控残差

计算 `residual + gate * branch`，显式保留乘法先落 BF16 的中间舍入。

| 行×列 | gate stride | InfiniCore mul+add ms | 九齿 ms | 比值 |
| --- | --- | ---: | ---: | ---: |
| 512×5376 | (32256,1) | 0.1007 | 0.0768 | 1.312× |
| 27570×5376 | (32256,1) | 4.5841 | 1.2285 | 3.732× |

单卡构造输入，rtol=atol=0 逐元素一致；5 轮、每轮 10 次调用，每次平均耗时的中位数，边界同步并包含 Python 调用开销。
单算子结果不等于模型整体收益，尚无九齿 C++ 实际路径接入证明。
Softmax 六种配置速度比为 0.246–0.480×，均保留原生。历史 SiLU 结果来自早期单卡 gfx906，不能混为 gfx936 模型收益。

## 定位进度

- 单卡构造数值：22 项满足各自容差，涵盖 Torch/Core 桥接、linear、RMSNorm、索引、短序列 MHA。
- 真实 DiT 权重、共同长度 104 构造输入：视频相对 RMSE TP2 0.8245%、TP8 0.9676%；音频 2.4056%、2.5540%。
- 重复前向有变化，TP8 视频重复相对 RMSE 2.0525%。前后同步变体没有改变首次对参考的误差统计。
- 这不是正式长度 27570 或完整去噪验证，不排除长序列、输入布局、条件编码及迭代交接问题。
- 条件编码探针准备对比同一官方输入下第 50 层特征，并用参考第 49/51 层辅助检查层索引；设备结果待回传。
